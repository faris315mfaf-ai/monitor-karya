## Cara membaca bukti

Dokumen baru menjelaskan keadaan kode yang diperiksa, bukan jaminan keadaan produksi. Angka tes adalah hasil 7 Oktober yang disimpan di repo, bukan pengujian ulang 8 Oktober. Path dalam paket relatif terhadap repo agar dapat dipindah mesin. Inventaris dibuat dari berkas Git/sumber; alat grafik codebase-memory tidak tersedia, sehingga tidak ada klaim penelusuran graf lengkap.

Instruksi manusia terbaru dan AGENTS tetap berlaku. Untuk pertentangan catatan historis gunakan bagian “Koreksi dokumen lama” pada laporan status ini. Jangan menganggap laporan bertanggal lama sebagai daftar tugas baru.
